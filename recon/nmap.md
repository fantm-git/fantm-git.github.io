# Nmap
Network Mapper is used for discovery and security auditing.

### Common Commands
`nmap -sV -sC -p- <target>`
`nmap -A <target>`

### Cross-Reference
If you identify port 161/162 open, proceed to the [SNMP Enumeration]({{fantm-git.github.io}}/services/snmp) page.
